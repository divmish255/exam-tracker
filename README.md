# BoardRank AI - 10th & 12th Board Exam Prep & Revision Portal

A modern, responsive, all-in-one web portal designed for Class 10th and 12th students across **CBSE, CISCE (ICSE/ISC), and State Boards (Maharashtra, UP, Bihar, Karnataka, etc.)**.

---

## 🚀 Instant Deployment to Vercel via GitHub

### Step 1: Create a GitHub Repository
1. Log into your [GitHub account](https://github.com/).
2. Click **New Repository** (e.g. `board-exam-portal`).
3. Leave it Public or Private and click **Create repository**.

### Step 2: Push the Files to GitHub
Open your terminal inside this folder and run:
```bash
git init
git add .
git commit -m "Initial commit - BoardRank AI Exam Portal"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/board-exam-portal.git
git push -u origin main
```

### Step 3: Deploy on Vercel
1. Log into [Vercel](https://vercel.com).
2. Click **"Add New..."** ➔ **"Project"**.
3. Select your newly created `board-exam-portal` GitHub repository.
4. Framework Preset: **Other** (Zero Configuration needed – static site ready).
5. Click **"Deploy"**.
6. In ~15 seconds, your site will be live with a free custom SSL domain (e.g., `https://board-exam-portal.vercel.app`)!

## ✨ Features Included

1. **Board, Class & Stream Selection**:
   - Supports CBSE, CISCE (ICSE/ISC), Maharashtra HSC/SSC, UP, Bihar, and State Boards.
   - Class 10th (General Curriculum) & Class 12th (Science PCM, Science PCB, Commerce, Humanities / Arts).
2. **Study, Sleep & Revision Calculator**:
   - Personalized schedule by academic performance (<60%, 60-80%, >80%).
   - Evidence-based REM sleep requirements and hour-by-hour daily timetable.
3. **Email Login & Weekly Performance Analytics**:
   - Saves email profile, target score, study streaks, and mock test scores locally.
4. **Interactive Syllabus Left Tracker**:
   - Chapter-wise mark weightage, status checkboxes (Completed, In-Progress, Backlog), and live % remaining calculator.
5. **MCQ Quiz & Mock Test Engine**:
   - Genuine Previous Years' Questions (PYQs 2020-2025) and high-probability predicted upcoming questions.
   - Real-time All India Rank (AIR) and percentile simulator across 180,000 nationwide students.
6. **Written / Subjective Answer Evaluator**:
   - Type answers to real 3-mark and 5-mark board questions.
   - Automated step-marking breakdown, missing examiner keywords analysis, and official model answers.
7. **Previous Year Question Papers (PYQ Vault)**:
   - Filterable board papers by year, subject, and class with marking schemes.
8. **Curated YouTube Revision Hub**:
   - Topic-wise one-shot revision videos and marathon lectures.
9. **Study Alarm & Live Board Exam Countdown**:
   - Synthesized Web Audio API alarm buzzer and chime (100% offline, zero external dependencies).
   - 50-minute Pomodoro study sprint and 10-minute break timer.
10. **Panic SOS & Mindset Gym**:
    - Animated 4-7-8 breathing circle pacer, 5-4-3-2-1 sensory grounding guide, and daily affirmations.
